Where this goes next

Stepped combs

A comb whose teeth sit at different heights gives every lane its own origin — an additive offset, independent of the chemistry. The comb then draws the coarse outline and the digest fills in detail. This is the biggest single lever available: Diagonal, Chevron and Wave all fail here (~57%) for the same reason — they need a smooth monotonic sweep that pUC19's fragment set cannot produce — and a stepped comb supplies exactly that. 3D-printable, but teeth need flat bottoms and an inert filament, and a tooth set lower has less running room beneath it.

Staggered loading

Pause the supply, load later lanes, resume. The shift this produces is multiplicative — it scales with each fragment's own mobility rather than displacing the whole lane equally, which is what a comb does. So the two controls are mathematically independent and compose into a much larger reachable set than either alone. The cost is that a lane loaded into an already-warm gel runs faster than one loaded at time zero, which is the same drift the calibration exists to measure.

Shaped and gradient gels

Casting an agarose gradient makes mobility a function of position, warping the size-to-distance map across the gel instead of applying one curve everywhere — regions could be compressed or expanded to suit different parts of the image. Harder to pour reproducibly and harder to calibrate. Note that merely shaping the gel's lower edge changes only where fragments run off, not where bands sit.

False colour

Intercalating stains emit in a single band, so colour has to be added after capture rather than acquired. Keying hue to the digest that produced each band is legible and defensible; presenting it as multi-channel acquisition is not. Labelled as false colour, it stays publishable — and since the app already knows which enzymes made every band, the mapping is free.

More sources widen the alphabet

This one is already done, and it mattered more than anything else tried. On pUC19 and pBR322 alone, Diagonal, Chevron and Wave were unreachable — 55 to 59%, because no single plasmid's fragment ladder produces a smooth monotonic sweep. Opening the search to all 42 plasmids lifted them to 88 to 91%, and did it while tightening the limit from three enzymes per digest to two. Each lane now picks whichever source places its bands best, so the reachable set grows combinatorially rather than additively. 27 of the 42 get used across the catalogue.

The migration model is not yet calibrated to this rig. Band positions come from a literature Van Winkle mobility model for TAE, and the run times it predicts disagree with the run sheets in Gen091226 by roughly twofold. Treat the shapes as achievable, the clock as provisional.

Sequences are read straight from the SnapGene files in PlasmidDB/ (A_1 to A_51, 40 circular plasmids, 2961 to 22895 bp) plus pUC19 L09137.2 and pBR322 J01749.1. The digest engine reproduces the published EcoRI, BamHI, HindIII, DraI and PvuII fragment sets exactly. Volts are derived from V/cm across the 36.8 cm electrode gap.

The enzyme panel is the VICTORA_LAB SnapGene set of 2021 combined with the enzymes that appear in 2023–2026 bench notes but are missing from it, since that file has gone stale. 88 of those 95 names exist in the digest engine; BfuAI, BmgBI, BsaAI, DpnI, PluTI, PspXI and SgrAI do not, so they are never proposed.

Buffer activity is parsed from NEB's published Performance Chart for Restriction Enzymes (2025): percent activity in r1.1, r2.1, r3.1 and rCutSmart for all 88 lab enzymes, with no value inferred. A digest is only proposed if one buffer carries every enzyme in it to the chosen threshold, and the table names the buffer and its worst-case activity. Where NEB now charts only an HF or v2 product, the recipe names that tube — KpnI-HF, BsaI-HFv2 — since the engineered variants have their own buffer profiles. Star-activity risks flagged by the chart are marked, and required cofactors (SAM for AcuI, BpuEI, BsgI and MmeI) are added to the buffer cell. Requiring one buffer per digest costs nothing here: the worst quality change across all 16 shapes was 0.0 points.

That table was cross-checked against an unrelated source — the REBASE file msbuffmore.txt in the local Geneious data, which lists NEB's recommended buffer for 1482 enzymes. 176 of 193 supplied buffers agree. Every one of the 17 differences is explained rather than unresolved: 15 are the parent-versus-variant distinction (REBASE gives KpnI in r1.1, the chart gives KpnI-HF in rCutSmart — both correct, about different tubes), and BstYI and HincII are cases where REBASE, dated 8/24, predates the 2025 chart. Agreement between two independently derived sources is the reason to trust these numbers; the parent/variant split is also why the recipe always names the product.
